**DocuSense lets your AI agent read your documents the way you would.** Instead of pasting a whole
50-page PDF into Claude or Cursor, your agent looks at the table of contents, opens the right section,
and reads only the paragraph that answers. Every answer comes with a citation to the exact passage.

It works with PDFs, Word files, web pages, Markdown and text. It runs on your computer, it's free, and
nothing is uploaded anywhere.

## What you get

## How much it saves

On the same set of questions:

| | Context your agent reads |
|---|---|
| Pasting the documents | 160,179 tokens |
| Typical retrieval (RAG) | 15,765 tokens |
| **DocuSense** | **6,869 tokens** |

For a single precise fact, that's 478 tokens instead of 9,090. You can see your own numbers any time with
`docusense savings`.

## Great for

- Long specs, API references and design docs while coding
- Policies, handbooks and contracts where you need exact wording
- Documents that change, where you need to know what's different
- Checking internal rules against an external standard

If your documents are a few short files that already fit in your agent's context, you don't need
DocuSense. It pays off on long documents, many documents, and documents your agent reads again and again.

## Works with

Claude Code, Claude Desktop, Cursor, and any other app that supports MCP (the standard way to give AI
agents tools).
